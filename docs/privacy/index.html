プライバシーポリシー

制定日：2026年11月9日
対象：「余白」iPhoneアプリおよび本サポートサイト
運営ブランド：sumi.inc

sumi.incは、以下の方針に従って情報を取り扱います。

1. タスクとフォルダの保存

タスクの内容、完了状態、フォルダはiPhone内に保存します。アプリには、これらを運営者のサーバーや広告サービスへ送信する機能はありません。独自の会員アカウントや、端末間の自動同期はありません。

2. 広告と外部サービス

無料版はGoogle AdMobのバナー広告を利用し、Google Mobile Ads SDKおよび同意管理用のUser Messaging Platformを組み込んでいます。広告の配信・測定、サービスの維持、不正防止のため、SDKはIPアドレス、端末・アプリの識別情報、広告やアプリの操作に関する情報、クラッシュ・パフォーマンス等の診断情報を取り扱う場合があります。IPアドレスから、おおよその地域が推定される場合があります。タスクの内容は広告SDKへ渡しません。

本アプリは非パーソナライズ広告を要求し、Googleのpublisher first-party IDとパーソナライズ処理を無効にしています。App Tracking Transparencyの許可要求は行いません。非パーソナライズ広告でも、広告配信や不正防止等に必要な情報が取り扱われます。

広告を要求する前に同意情報を確認し、必要な地域では同意フォームを表示します。プライバシー選択の変更が必要な地域では、アプリの設定にある「広告のプライバシー設定」から変更できます。

広告オフの利用権の確認中および有効な契約期間中は、広告を要求・表示しません。すでに初期化されたSDKそのものを、セッション中に取り除くものではありません。

Googleが取り扱う情報、保存期間、処理する国・地域や利用者の選択については、Googleのプライバシーポリシー、Googleの広告に関する説明をご確認ください。

3. 購入とサブスクリプション

広告オフの月額プランは、Appleのアプリ内課金を利用します。アプリはStoreKitを通じて購入商品と利用権の有効性を確認します。運営者がカード番号を受け取ることはありません。Appleによる決済・取引情報の取り扱いは、Appleのプライバシーポリシー等に従います。

4. バックアップとデータの削除

利用者の操作で、タスクとフォルダを含むJSONファイルを書き出せます。保存先・共有先は利用者が選択します。端末の設定によっては、アプリ内データがiOSのバックアップ対象になります。

タスクはアプリ内から削除できます。フォルダの削除時はタスクを未分類へ移します。アプリ削除時の端末内データはiOSの動作に従います。書き出したファイルやOSのバックアップは、各保存先で別途管理・削除してください。運営者はタスクデータを保管していないため、削除したタスクの取り出しや復旧はできません。

5. お問い合わせで受け取る情報

問い合わせメールに含まれるメールアドレス、本文、利用者が添付した情報を、返信・問題の調査・サポート対応のために使用します。対応や記録の維持に必要な期間に限って保持し、不要になった情報は削除します。法令等に基づき保持が必要な場合は、その期間保持します。メールの処理にはGoogleのメールサービスを利用します。

Appleのパスワード・確認コード、決済情報、タスクのバックアップを送る必要はありません。問い合わせ情報の確認・訂正・削除等の相談は、下記窓口へご連絡ください。

6. サポートサイト

本サイトには独自の広告、アクセス解析ツール、問い合わせフォームを設置していません。ページの配信にはGitHub Pagesを利用します。サイトの配信・保護のため、ホスティング事業者がIPアドレスやアクセス情報を取り扱う場合があります。詳細はGitHubのプライバシーに関する声明をご確認ください。

この方針は、別途提供されるWeb版Todoアプリの認証サービスには適用しません。

7. 方針の変更

機能や外部サービス、情報の取り扱いを変更する場合は本方針を更新し、このページでお知らせします。
