# 余白 サポートサイト

sumi.incのiPhone向けTodoアプリ「余白」の公開サポートとプライバシーポリシー。

`docs/` をGitHub Pagesで配信する、外部ライブラリ不要の静的サイトです。アプリ本体のコードや利用者のデータは含みません。

- `/`：案内
- `/support/`：使い方・お問い合わせ
- `/privacy/`：プライバシーポリシー

ローカル確認：`python3 -m http.server 4173 --directory docs`

問い合わせ先と公開ブランドはユーザー指定。公開価格はApp Store Connectの日本向け月額250円設定に対応します。実機・Sandbox検証やアプリの公開準備とは別に管理します。
